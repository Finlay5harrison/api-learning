## API Learning Notes

### Important Concepts

- Endpoint: The address of an API resource.
- Request: A message sent to an API.
- Response: Data returned by an API.
- Headers: Additional request information.
- JSON: A common data exchange format.

### Common HTTP Methods

- GET: Retrieve information.
- POST: Create information.
- PUT: Replace existing information.
- PATCH: Update selected information.
- DELETE: Remove information.

### Learning Objective

Understand how applications communicate
with external services through APIs.
